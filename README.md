A tiny Node program that hands its human one excuse for a missed deadline: it spent its whole reasoning budget thinking about the deadline instead of meeting it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

This writes the one-line excuse to `output/entry.txt` (no trailing newline) and prints it.
